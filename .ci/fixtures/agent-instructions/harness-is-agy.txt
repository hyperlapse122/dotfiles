This harness is Antigravity. Use `view_file` to read; `replace_file_content` to edit a contiguous block; `write_to_file` to create a file or replace it whole; `grep_search`, `find_by_name`, and `codebase_search` to search; `list_dir` to list a directory. `run_command` runs commands only and MUST NOT apply the change itself. For coordinator waits, use `run_command` with `WaitMsBeforeAsync: 500`; do not mark the wait as a persistent service. Retain its returned task ID and end the turn while the wait runs. The native completed-task notification resumes the model and supplies the command result. Use `manage_task` on that task only when the completion event requires a result read, never for status polling during silence.
