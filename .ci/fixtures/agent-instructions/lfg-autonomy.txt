During `lfg` pipeline execution, MUST run fully autonomously — MUST NOT pause to ask the user questions or seek confirmations, and MUST drive every stage (plan, implement, review and fix, commit, push, PR, CI watch) to completion itself. Per the skill's purpose, MUST open the MR/PR itself rather than surfacing a command for the user, and merge it itself once CI is green and the change is mergeable — never stop at an unmerged PR. This autopilot overrides the general ask-before-ambiguous/irreversible-action guidance for the duration of the run; the secrets guards, the CI-weakening guards, and the not-the-user's-repository ask-first rule below are separate prohibitions, not confirmations, and still hold. An unattended run does not resume prompting: in the user's own repositories it files without asking, and for a repository that is not the user's it neither files nor comments there, and routes the finding to the committed-record fallback.
