# Web lenses

For HTML, CSS, web UI, and browser JavaScript, read modern web guidance first, alongside the other applicable guides. Apply the design-lenses craft floor to every UI edit. For new screens, use frontend-design for visual direction and apply the other guidance within that direction.

Read the guide relevant to the task before starting:

- [Modern web guidance](references/modern-web-guidance/modern-web-guidance.md) for HTML, CSS, and browser JavaScript.
- [Frontend design](references/frontend-design/frontend-design.md) for visual direction.
- [Web design guidelines](references/web-design-guidelines/web-design-guidelines.md) for interface review.
- [React best practices](references/vercel-react-best-practices/vercel-react-best-practices.md) for React performance.
- [React composition patterns](references/vercel-composition-patterns/vercel-composition-patterns.md) for component APIs.
- [Playwright best practices](references/playwright-best-practices/playwright-best-practices.md) for browser tests.

For TanStack, tRPC, or another dependency that ships its own skills, open `project-skills` in the package you are changing.

For UI flows and states, also read the separate design-lenses entry. For interface copy, read writing-lenses.
