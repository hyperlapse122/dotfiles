# Engineering lenses

Read the guide relevant to the task:

- [Find documentation](references/find-docs/find-docs.md) for library and framework documentation.
- [CLI design](references/cli-design/cli-design.md) for command-line interfaces.
- [Untangle codebase](references/untangle-codebase/untangle-codebase.md) for structural refactoring.
- [Test audit](references/test-audit/test-audit.md) for writing or reviewing tests.
- [Prune tests](references/prune-tests/prune-tests.md) for test cleanup.

For an npm dependency, open `project-skills` to look for a guide shipped with the installed version. For Rust, TypeScript or Java language questions, use find-docs to locate the language maintainer's documentation for the project's toolchain version.

For test cleanup, read both prune-tests and test-audit, and follow the repository testing policy.

For CLI flows and states, also read the separate design-lenses entry; for interface copy, read writing-lenses.
