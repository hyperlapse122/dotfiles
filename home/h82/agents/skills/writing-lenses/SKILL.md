# Writing lenses

Read the guide relevant to the task:

- [Humanizer](references/humanizer/humanizer.md) for natural Korean prose.
- [Grammar checker](references/grammar-checker/grammar-checker.md) for Korean grammar and spelling.
- [Style guide](references/style-guide/style-guide.md) for consistent Korean documents.
- [UX writing](references/ux-writing/ux-writing.md) for interface copy.

Apply writing guidance silently to final answers, handoffs, documents, commit and PR text, issues, and user-facing strings. For Korean, use humanizer followed by grammar-checker; also use style-guide for multi-section or edited documents. For English, use the native CE ce-noslop skill. Progress notes, questions, child reports, code, configuration, comments, docstrings, and verbatim text are exempt.
